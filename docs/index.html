Install on Debian/Ubuntu 
wget "https://github.com/pubky/pubky-chromium/releases/download/pubky-linux-156.0.8078.48/pubky-chromium_156.0.8078.48-1_amd64.deb"
sudo apt install "./pubky-chromium_156.0.8078.48-1_amd64.deb"

Ubuntu App Center shows a generic “Unknown publisher” warning for any local .deb; terminal install avoids it.
